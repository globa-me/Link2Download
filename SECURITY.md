# Security policy

## Reporting a vulnerability

Please do not publish security vulnerabilities in a public issue. Use GitHub's **Report a vulnerability** option in the repository Security tab to send a private report to the maintainer.

Include the affected version and platform, reproduction steps, expected impact and any suggested mitigation. Remove browser cookies, tokens, signed URL parameters, account details and personal file paths from screenshots and logs.

You can expect an acknowledgement after the report is reviewed. A public disclosure timeline will be coordinated after a fix is available.

## Supported versions

Security fixes target the latest published release. Preview Windows builds and older macOS releases may require upgrading before a fix can be applied.
